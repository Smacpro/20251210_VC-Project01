# Changelog

Alle wichtigen Änderungen an diesem Projekt werden in dieser Datei dokumentiert.

## [1.0.0] - 2024-12-10

### Hinzugefügt

#### Kernfunktionen
- ✨ Freitextsuche über alle Angebote
- ✨ Persona-basiertes Empfehlungssystem (5 Personas)
- ✨ Kategoriefilter (Veranstaltungen, Förderung, Publikationen, etc.)
- ✨ Erweiterte Filter:
  - Zeitraum (nächste Woche, Monat, 3 Monate, benutzerdefiniert)
  - Veranstaltungsort (vor Ort, online, hybrid)
  - Kosten (kostenlos, kostenpflichtig)

#### Personas
- 🎓 Einsteiger - Neu in der Medienbranche
- 🔄 Quereinsteiger - Aus einer anderen Branche
- 💼 Professional - Erfahrener Medienschaffender
- 🚀 Gründer - Unternehmer im Medienbereich
- 📚 Student - In Ausbildung oder Studium

#### UI/UX
- 🎨 Responsives Design (Mobile, Tablet, Desktop)
- 🎨 Farbcodierte Angebotstypen
- 🎨 Interaktive Filterkarten
- 🎨 Echtzeit-Suchergebnisse
- 🎨 Übersichtliche Ergebnisdarstellung

#### Datenquellen (20 Beispiel-Angebote)
- Blauer Panther Award
- Games Bavaria
- Mediennetzwerk Bayern
- Media Lab Bayern
- KI Kompetenzzentrum Medien
- XPLR Media
- XR Hub Bavaria
- Start into Media
- Medientage München

#### Technische Features
- ⚡ Vanilla JavaScript (keine Abhängigkeiten)
- ⚡ Modulare Architektur
- ⚡ Einfache Integration
- ⚡ JSON-basierte Datenstruktur
- ⚡ Intelligentes Relevanz-Scoring

#### Integration-Optionen
- 🔌 Standalone-Seite
- 🔌 iFrame-Integration
- 🔌 Direkte Integration

- 🔌 WordPress-Integration (Templates, Shortcodes, Blocks)

### Optimierungen

- 🚀 Performance-optimiert für schnelle Ladezeiten
- 🚀 Lazy Loading Support
- 🚀 CSS-Grid für effizientes Layout
- 🚀 Debounced Search (verhindert zu viele Suchen)

### Browser-Unterstützung

- ✅ Chrome/Edge 90+
- ✅ Firefox 88+
- ✅ Safari 14+
- ✅ Opera 76+

### Bekannte Einschränkungen

- ⚠️ Internet Explorer nicht unterstützt
- ⚠️ Statische Daten (keine Backend-Integration in v1.0)
- ⚠️ Keine Benutzerkonten/Favoriten (geplant für v2.0)
